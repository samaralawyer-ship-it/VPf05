Модуль читает файл inputdata/orders.csv с колонками category и amount.
Считает сумму и количество заказов по каждой категории.
Пишет outputdata/output.json — JSON-конверт с бизнес-результатом внутри поля output
(в output.categories: список {"name": "строка", "count": 0, "total": 0.0}),
и наглядный файл outputdata/output.txt с построчным отчётом.
Только стандартная библиотека Python. Без сети и без установки зависимостей.
